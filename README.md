# Audi Used-Car Price Predictor

Interactive portfolio demo for the reproducible ML pipeline in the associated GitHub project.

The app loads a pre-trained scikit-learn pipeline and returns a predicted vehicle price from model, year, transmission, mileage, fuel type, tax, MPG, and engine size.

This demo is for educational and portfolio use.
